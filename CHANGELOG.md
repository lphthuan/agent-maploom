# Changelog

## 0.2.0 — 2026-10-07

First public AgentMaploom release, following a local prototype.

- Windows bootstrap with pinned dependency/helper installation and offline cache reuse.
- One short root AGENTS map, preserved project rules, project wrappers and VS Code tasks.
- C#/TS/JS structural maps, Unity assembly/GUID references and bounded source/context retrieval.
- Durable task briefs, local memory, checkpoint/resume and source-aware evidence handoff.
- Configurable basic/full verification; mandatory checks retained; No-mistakes restricted to full.
- Pinned Graft, Memory MCP, Lavish and native No-mistakes adapters; AXI-style compact CLI output.
- Public `agent-maploom` entry point, English/Vietnamese guides, MIT license, source ZIP and npm-format tarball with SHA-256 checksums.

Known limits: only Windows setup is validated; Unity Editor/modules/MCP require user configuration; native full gates require separate initialization and authenticated agent CLI; no account switching or automatic chat restoration.
