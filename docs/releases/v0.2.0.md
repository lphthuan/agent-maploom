# AgentMaploom v0.2.0

First public release: project setup, code maps and local context for AI coding agents, focused on Unity C#.

## Install

1. Download `agent-maploom-v0.2.0-windows-source.zip` and compare its SHA-256 with `SHA256SUMS.txt`.
2. Extract it and open PowerShell in `agent-maploom-0.2.0`.
3. Run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1 -Project 'D:\Games\MyUnityGame'
```

Use your project's actual path. Keep the extracted toolkit folder. First setup downloads pinned runtime/dependencies/helpers; the ZIP is source plus bootstrap, not a full offline installer.

## Included

- Short AGENTS map with preserved project rules, C#/TS/JS source maps and bounded context.
- Local task brief, memory, checkpoint/resume and evidence handoff.
- Configurable basic/full tests; No-mistakes only in full.
- Pinned Graft 0.21.1, Memory MCP 2026.8.31, Lavish 0.1.83 and No-mistakes 1.84.0 installation.
- AXI-style CLI, VS Code tasks, `agent-maploom` npm-format CLI and MIT license.

## Assets

- Windows source ZIP: recommended setup path.
- `agent-maploom-0.2.0.tgz`: install from the downloaded file using npm on Node.js 24+; not published to the npm registry.
- `release-manifest.json`: public source hashes and archive metadata.
- `SHA256SUMS.txt`: asset checksums.

## Validation and limits

Release preparation checks TypeScript, regression tests, archive contents/checksums and clean installation. Package smoke exercises C# context retrieval, rule preservation, actual Node tests, saved context and handoff. These checks do not prove live Unity gameplay or a completed native full gate.

Windows setup is validated; macOS/Linux CLI is experimental. Unity Editor/license, mobile SDKs/modules, MCP/Test Framework and authenticated agent configuration remain user-provided. No-mistakes needs separate gate initialization. Account switching, full chat migration and background wake-up are outside this release.
